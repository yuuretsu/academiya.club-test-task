В моей реализации выполнены все требования, включая необязательные (синхронизация цвета и размера одежды через url, промокод в корзине)

Решил создать проект с нуля, чтобы использовать typescript для обеспечения строгой типизации (если бы проект требовал чистого js, покрыл бы код типами, используя JSDoc) и vite для быстрой сборки

В качестве менеджера состояния выбрал mobx. Для синхронизации состояния с localStorage выбрал mobx-persist-store, для синхронизации состояния с url написал кастомную адаптацию для mobx-persist-store с интерфейсами как у localStorage

Для работы с реакт контекстом написал утилиту через фабрику контекста с HOC

Процесс решения задания был примерно такой:

Сначала спроектировал архитектуру и написал код основной страницы, задав дизайн систему. На этапе прототипирования набросал стили в инлайне, затем использовал ИИ-агента, чтобы перенести стили на модульный css, и используя пример реализованной мной страницы сгенерировать страницу карточки товара и корзины.
